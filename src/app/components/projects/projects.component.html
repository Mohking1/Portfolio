01 / FLAGSHIP SYSTEM Pure-ML · Reinforcement Learning

Creature — Multi-Terrain RL Physics Platform

A custom browser-integrated physics simulation and continuous-control reinforcement learning platform. Evaluates deep RL policies (PPO) across procedurally generated 100m championship tracks with complex obstacles, slopes, steps, and variable-friction surfaces.

▸
Verlet & Euler Physics Engine: 60 FPS real-time kinematics with joint torque limits and ground reaction impulse modeling.
▸
12-DoF Hexapod Spider Policy: Trained with continuous PPO control, generalized joint actuation, and distance-penalized reward functions.
▸
Procedural Terrain Curriculum: Seamless 100m transitions: Flat, Ice & Mud (0.05-2.5μ), 15° Slopes, Stepped Terraces, and Hurdles.
▸
LiDAR Raycasting & Sensors: Real-time proximity rays, joint strain heatmaps, and contact pressure vectors rendered on canvas.

Local ML Experiment Tracker & Profiler

A zero-cloud, high-performance experiment tracking and model evaluation engine. Replaces slow cloud dependencies with a local SQLite WAL catalog, streaming loss/accuracy telemetry, PyTorch gradient norm hooks, and comprehensive confusion matrix evaluation.

▸
Zero-Cloud SQLite WAL Storage: Sub-millisecond local run indexing in ~/.experiment_tracker/ without external servers or network bottlenecks.
▸
PyTorch Gradient Diagnostics: Automatic backward hook registration via run.watch(model) for gradient norm monitoring and layer diagnostics.
▸
Multi-Class Evaluation Matrix: Computes multi-class ROC-AUC (0.9249), 3x3 interactive confusion matrix, and MDI feature importances.
▸
Reproducibility & Weight Checkpoints: Automatic hyperparameter hashing, environment fingerprinting, and PyTorch model state dict serialization.

03 / FLAGSHIP SYSTEM Autonomous Multi-Agent Systems

Argus OS — Topological Multi-Agent Executive

An offline-first executive AI operating system that compiles complex natural language goals into deterministic directed acyclic graphs (DAGs). Coordinates specialized subagents across email intelligence, multimodal document parsing (Docling + IBM TableFormer), zero-cloud web research (SearXNG), and persistent cognitive memory (SQLite Loci-Hindsight) with supervised safety gating.

▸
Topological DAG Planning Engine: Decomposes goals into cycle-free dependency graphs with parallel branch execution and verified receipts.
▸
Blackboard Variable Interpolation: Downstream steps dynamically consume verified artifacts ($step_1.saved_paths -> $step_2a.table_matrix).
▸
Docling + IBM TableFormer Extraction: Deep multimodal parsing retaining complex table column hierarchies, cell spans, and figures in a deduplicated vault.
▸
Cognitive Loci Memory & Web Metasearch: SQLite FTS5 spatial knowledge storage + local SearXNG metasearch for zero-cloud benchmark discovery.
▸
Supervised Autonomy Safety Policy: Policy engine intercepting direct external SMTP actions and staging formatted counter-offer emails in Drafts.
